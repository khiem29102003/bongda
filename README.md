# Thiệp chúc mừng ngày 20/10

Website thiệp 20/10 responsive, có hiệu ứng cánh hoa rơi, nền phát sáng, nút mở lời chúc và trái tim bay. Chỉ cần HTML/CSS/JavaScript thuần, không cần build.

## Chạy thử trên máy
Mở `index.html` bằng trình duyệt.

## Đưa lên GitHub Pages để có đường link công khai
1. Đăng nhập GitHub và tạo repository mới, ví dụ `thiep-20-10`.
2. Upload `index.html` (hoặc giải nén toàn bộ thư mục rồi upload file).
3. Vào **Settings → Pages**.
4. Trong **Build and deployment**, chọn **Deploy from a branch**.
5. Chọn branch `main`, folder `/ (root)`, rồi nhấn **Save**.
6. Đợi GitHub triển khai. Đường link thường có dạng:
   `https://TEN-TAI-KHOAN.github.io/thiep-20-10/`

Thay `TEN-TAI-KHOAN` bằng tên tài khoản GitHub của bạn. Link chỉ hoạt động sau khi bạn tạo repository và bật GitHub Pages.

## Tùy chỉnh lời chúc
Mở `index.html`, tìm đoạn `Chúc bạn luôn xinh đẹp...` và sửa lời chúc theo người nhận.
